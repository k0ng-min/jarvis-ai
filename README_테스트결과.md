### 2단계: "자비스" 호출 후 질문하기

**테스트 질문 목록:**

1. **시간 확인**
   - "자비스, 현재 시각이 몇 시야?"
   - "자비스, 지금 몇 시야?"
   - 예상 결과: 현재 시간 즉시 응답

2. **날짜 확인**
   - "자비스, 오늘 날짜가 뭐야?"
   - "자비스, 오늘은 무슨 요일이야?"
   - 예상 결과: `2026년 06월 25일 목요일`

3. **날씨 정보**
   - "자비스, 서울 날씨는?"
   - "자비스, 부산 기온은?"
   - "자비스, 대구는 비 와?"
   - 예상 결과: 해당 도시의 날씨 정보 조회

4. **뉴스/정보 검색**
   - "자비스, 오늘의 뉴스는?"
   - "자비스, 최신 기술 뉴스 검색해줘"
   - 예상 결과: Claude가 웹 검색을 통해 정보 제공

5. **유튜브**
   - "자비스, 유튜브에서 음악 틀어줘"
   - "자비스, 유튜브에서 고양이 영상 재생해"
   - 예상 결과: 유튜브 검색/재생

6. **앱 실행**
   - "자비스, 크롬 열어줘"
   - "자비스, 메모장 실행해"
   - 예상 결과: 앱 실행

## 🔧 주요 기능 아키텍처

### 1. 빠른 응답 (로컬 처리)
- "몇 시야?" → 즉시 시간 응답
- "오늘 날짜" → 즉시 날짜 응답
- Claude API 호출 없이 즉각 반응

### 2. 도구 라우팅
```
입력 → 키워드 분석 → 도구 선택 → 실행
```
- `weather_report`: 날씨 조회
- `youtube_video`: 유튜브 검색/재생
- `web_search`: 웹 검색
- `open_app`: 앱 실행
- `browser_control`: 브라우저 제어
- 등 15+ 도구

### 3. Claude AI 응답
- 로컬 처리 불가한 복잡한 질문은 Claude가 처리
- 대화 맥락 유지 (세션 ID)
- 한국어 전용 강제

## 🐛 문제 해결

### 마이크 인식 안 됨
```bash
python check_mics.py  # 마이크 번호 확인
# main.py 라인 57 수정: MIC_INDEX = <번호>
```

### Claude 응답 없음
```bash
# Claude CLI 설치 확인
claude --version

# Claude Code 설정 확인 (API 키 등록 필요)
```

### GUI 창 안 떠짐
```bash
# PyQt6 관련 의존성 확인
pip install -r requirements.txt
```
