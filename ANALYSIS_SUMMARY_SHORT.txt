🔍 KEY FINDINGS FROM 10 PROJECTS
================================================================================

STT (Speech-to-Text):
  ├─ Google Speech-to-Text: High accuracy, Korean support, API cost
  ├─ Whisper: Offline, multilingual, CPU/memory heavy
  ├─ Faster-Whisper: 3x faster than Whisper
  └─ Best: Faster-Whisper for Korean with RMS-based VAD

TTS (Text-to-Speech):
  ├─ Edge-TTS: Korean excellent, fast, reliable ← RECOMMENDED
  ├─ pyttsx3: Fallback, fast, low quality ← FOR FALLBACK
  ├─ Tacotron: Character voice, customizable
  └─ Best: Edge-TTS + pyttsx3 fallback chain

Wake Word:
  ├─ Fuzzy Matching: Fast (<10ms), handles slurred speech
  ├─ LLM Intent: Accurate, echo detection, 1-2s overhead
  └─ Best: Fuzzy for speed, LLM for unclear cases

Timeout Strategy:
  ├─ STT: 6s input wait / 10s max speech length
  ├─ Claude: 15s (ours) vs 30s (default) ← WE DID IT!
  └─ Tool ops: 60s / 300s idle timeout

Error Recovery:
  ├─ Classification: API errors → Retry | Network → Replan
  ├─ Our error_handler.py: 4 decisions (Retry/Skip/Replan/Abort)
  └─ Best practice: Exponential backoff + Fallback chains
